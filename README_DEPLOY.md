# Portfólio bilíngue de Ivana Bezerra / Bilingual Portfolio

## Publicar no GitHub Pages

1. Abra o repositório `ivanafbezerra-afk.github.io` no GitHub.
2. Substitua o `index.html` da raiz e envie `styles.css` e `main.js` para a raiz.
3. Adicione a pasta `pt` com o arquivo `pt/index.html`.
4. Envie `ivana-bezerra-resume-en.pdf` para a raiz (o currículo original `curriculo-ivana-bezerra.pdf` também permanece).
5. Mantenha as imagens, PDFs e outros arquivos que já existem no repositório. O ZIP desta entrega já inclui todos eles.
6. Confirme em **Settings > Pages** que a publicação usa a branch correta (em geral `main`, pasta `/ (root)`).
7. Acesse `https://ivanafbezerra-afk.github.io/` (inglês) e `https://ivanafbezerra-afk.github.io/pt/` (português). Teste os filtros, botões, PDFs e links externos.

## Como funcionam as versões

- Inglês na página inicial, português em `/pt/`.
- Idioma selecionável no cabeçalho: **EN | PT**.
- As duas versões usam o mesmo CSS e JavaScript; não dependem de bibliotecas externas.
- O botão de currículo da página em inglês aponta para o PDF em inglês; o botão da página em português aponta para o PDF original.
- Os **quatro PDFs de estudos de caso continuam em português**, sinalizados como `PDF · PT` na versão em inglês. Tradução dos PDFs não foi incluída.
- Os dashboards e páginas externas continuam com os links originais. O conteúdo e idioma desses destinos externos não foram alterados.

## Arquivos principais

- `index.html` — site em inglês
- `pt/index.html` — site em português
- `styles.css` — estilo preservado com ajustes para alternância de idioma
- `main.js` — filtros de projetos
- `ivana-bezerra-resume-en.pdf` — currículo internacional em inglês
- `curriculo-ivana-bezerra.pdf` — currículo original em português

**Observação:** este pacote não publica alterações automaticamente no seu repositório.
